# Face Detection Project

This project detects human faces in real time using Python and OpenCV.

## Features
- Real-time face detection
- Webcam support
- AI-based face recognition box
- Simple beginner-friendly project

## Technologies Used
- Python
- OpenCV

## Project Structure

Face-Detection-Project
│
├── face_detect.py
├── requirements.txt
└── README.md

## Installation

Install required library:

```bash
pip install opencv-python
```

## Run Project

```bash
python face_detect.py
```

## How It Works
- Opens webcam
- Detects face using OpenCV Haar Cascade
- Draws green rectangle around detected face
